# Class Group Maker

A simple browser app that helps teachers create varied student groups.

## Features
- Create groups quickly for class activities
- Mark absent students
- Save multiple classes
- Keep earlier groups in mind to avoid repeating the same combinations too often
- Works directly in the browser
- No server or setup required

## How to use
1. Choose a class
2. Add or update students
3. Mark absent students
4. Choose a group size
5. Create groups

## Run locally
Open the HTML file in your browser.

## Privacy
All data stays in your browser on your device.
