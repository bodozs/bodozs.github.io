# Mac

| Hotkey | Function                                                                                          |
| :----: | :------------------------------------------------------------------------------------------------ |
|   ⌘?   | search in menus of an app. <br> In Safari it searches in bookmarks as well (Help menu search box) |
|  Fn F  | toggle full screen                                                                                |

# Teams

| Hotkey | Function                |
| :----: | :---------------------- |
|   ⌘G   | go to a chat or channel |
|   ⌘1   | Go to Activity          |
|   ⌘2   | Go to Chat              |
|   ⌘3   | Go to Teams             |
|   ⌘4   | Go to Calendar          |
|   ⌘5   | Go to Calls             |
|   ⌘6   | Go to Files             |
|  ⌘⇧X   | Expand compose box      |
|   ⌘E   | Go to search bar        |
|   ⌘/   | Open command box        |

# Internet explorer

| Hotkey | Function                                                       |
| :----: | :------------------------------------------------------------- |
|   ⌘L   | go to address bar, then type @ to search between the open tabs |
|   @    | choose search filter in address bar                            |
|   %    | search between open tabs in address bar                        |
|   ^    | search history in address bar                                  |
|   *    | search favorites in address bar                                |


# Write special characters

With option key
- Apple/Command: 2318 ⌘ 
- Alt/Option: 2325 ⌥ 
- Shift: 21E7 ⇧ 
- Delete: 232B ⌫ 
- Control: 2303 ⌃ 
- Apple Logo: F8FF or Option-Shift-K 
- ⮕ U+2B95
- ⬅ U+2B05
- ⬆ U+2B06
- ⬇ U+2B07
