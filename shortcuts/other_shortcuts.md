- Mac
	- ⌘? - search in menus of an app. In Safari it searches in bookmarks as well (Help menu search box)
  
- Cleanshot
	- Cmd + Shift + 4 - screenshot area
- Confluence wiki
	- Inline code formatting - {{ }}
  
- Teams
	- ⌘ + G - go to a chat or channel
	- ⌘ + 1: Go to Activity
	- ⌘ + 2: Go to Chat
	- ⌘ + 3: Go to Teams
	- ⌘ + 4: Go to Calendar
	- ⌘ + 5: Go to Calls
	- ⌘ + 6: Go to Files
	- ⌘ + Shift + X: Expand compose box
    - ⌘ + E: Go to search bar
    - ⌘ + /: Open command box
  
- Teams - Copilot chat
	- Option + Shift + Enter - add line break in copilot chat
	- ⇧ Shift + ⌥ Option + ⌘ Command + A - select content of the chat window
  
- iTerm2
	- Command + Shift + O - Open quickly command palette
  
- Internet explorer 
	- Command + L: go to address bar, then type @ to search between the open tabs
