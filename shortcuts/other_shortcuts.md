# Teams
| Hotkey | Function                |
| :----: | :---------------------- |
|   ⌘G   | go to a chat or channel |
|   ⌘1   | Go to Activity          |
|   ⌘2   | Go to Chat              |
|   ⌘3   | Go to Teams             |
|   ⌘4   | Go to Calendar          |
|   ⌘5   | Go to Calls             |
|   ⌘6   | Go to Files             |
|  ⌘⇧X   | Expand compose box      |
|   ⌘E   | Go to search bar        |
|   ⌘/   | Open command box        |

# Write special characters  
With option key
- Apple/Command: 2318 ⌘ 
- Alt/Option: 2325 ⌥ 
- Shift: 21E7 ⇧ 
- Delete: 232B ⌫ 
- Control: 2303 ⌃ 
- Apple Logo: F8FF or Option-Shift-K 
